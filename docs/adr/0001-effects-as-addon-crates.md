# Эффекты как крейты-аддоны

Эффекты будут добавляться постоянно, но динамической загрузки кода на ESP32 нет (нет ОС и файловой системы для плагинов), поэтому Аддон — это отдельный `no_std`-крейт workspace с общим трейтом эффекта, а новый эффект попадает на Гирлянду только вместе с новой Прошивкой: зависимость в крейте прошивки плюс одна строка в статическом Реестре эффектов (список фабрик `fn(Params) -> Box<dyn Effect>`). Крейты аддонов не зависят от esp-hal, поэтому их математика тестируется `cargo test` на хосте.

## Considered Options

- **Динамические плагины** — невозможны: на устройстве нет загрузчика модулей; плагин потребовал бы собственного ELF-лоадера и ABI эффектов.
- **Готовая библиотека с закрытым enum-реестром** (smart-leds-fx) — сторонний крейт не может добавить вариант enum'а, реестр принадлежит автору библиотеки; тупик для аддонов.
- **Статический Реестр фабрик** (принято) — реестр лежит в `.rodata` без рантайм-инициализации, состояние эффекта инкапсулировано в аддоне.
