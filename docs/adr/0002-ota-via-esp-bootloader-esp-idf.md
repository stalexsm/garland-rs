# OTA через esp-bootloader-esp-idf

Прошивка должна обновляться по воздуху и уметь Откат при неудачном обновлении. Решение: официальный крейт `esp-bootloader-esp-idf` 0.6.0 (`OtaUpdater`: выбрать неактивный Слот → записать образ чанками → активировать → перезагрузка) поверх таблицы разделов `nvs` + `otadata` + `ota_0` + `ota_1`; доставку образа делает собственный мини-HTTP-сервер и веб-страница Гирлянды (HTTP без TLS — только внутри домашней сети). Откат нового образа при зависании даёт только собственный Загрузчик, собранный с `CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y` (в prebuilt-загрузчике espflash он выключен), поэтому после старта Прошивка сама подтверждает свой слот (`Valid`) — без подтверждения Откат не сработает никогда.

## Considered Options

- **esp-hal-ota** — живой, но автор прямо пишет, что не тестирует ESP32-C6; docs.rs-доки не собираются.
- **esp-ota** — не `no_std` (ESP-IDF/std); **esp-ota-nostd** — замороженный эксперимент без репозитория.
- **Свой OTA-слой** — не нужен: протокол otadata уже реализован в официальном крейте из монорепо esp-hal с CI по всем чипам, включая C6.
